## Features

<CardGrid>
	<Card title="One window, one document" icon="document">
		Every document opens in its own window, so Windows itself manages them.
		No projects, no workspaces, no tabs to manage.
	</Card>
	<Card title="Part of your shell" icon="seti:powershell">
		`azu` opens files from the command line, waits for a window to close, and
		reads or edits text in a pipeline. See the
		[command-line reference](/azunyan/docs/command-line/).
	</Card>
	<Card title="External tools" icon="setting">
		Run any program on the document or selection, then insert, replace,
		propose a change, or show problems from its output. See
		[external tools](/azunyan/docs/external-tools/).
	</Card>
	<Card title="Command palette" icon="magnifier">
		Ctrl+Shift+P searches every menu command, the other windows, and recent
		files.
	</Card>
	<Card title="Language modes" icon="seti:json">
		Highlighting for C#, JavaScript, TypeScript, Python, JSON, XML, YAML, TOML,
		Markdown, PowerShell, and diffs, with folding and custom modes.
	</Card>
	<Card title="Plain-text settings" icon="pencil">
		Settings, tools, and modes are TOML files, completed as you type and
		reloaded when they change. See [settings](/azunyan/docs/settings/).
	</Card>
</CardGrid>
