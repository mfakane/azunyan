Azunote runs on Windows x64 and ARM64. Get it from the Microsoft Store, or
download the portable version to run without installing.

## Microsoft Store

The Microsoft Store installs Azunote and keeps it up to date.

## Portable

The portable version runs from any folder, such as a USB drive, and keeps its
settings in the `appdata` folder inside it.

1. Download the ZIP for your device from the
   [latest release](https://github.com/mfakane/azunyan/releases/latest):
   `Azunote-<version>-win-x64.zip` for most PCs, or
   `Azunote-<version>-win-arm64.zip` for Windows on Arm. Settings > System >
   About shows which one you have under System type.
2. Extract the whole folder and run `Azunote.exe`.

To update, extract the new ZIP and copy the `appdata` folder from the old one
into it. Each ZIP has a `.sha256` file for checking the download.
