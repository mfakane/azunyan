## GitHub releases

[GitHub releases](https://github.com/mfakane/azunyan/releases/latest) provide
downloads for Windows x64 and ARM64:

- **Portable ZIP** — `Azunote-<version>-win-x64.zip` or
  `Azunote-<version>-win-arm64.zip`. Extract the whole folder for your device
  and run `Azunote.exe`; nothing is installed.
- **Installer** — `Azunote-<version>.msixbundle` contains both architectures.
  It is currently unsigned, so it must be signed with a certificate the machine
  trusts before it can be installed.

Each file has a `.sha256` sidecar.
