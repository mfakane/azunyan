# Azunote

Azunote is a lightweight Windows text editor with one document per window.

Run `Azunote.exe` to open the editor. Use `azu.exe` from a command prompt or
PowerShell to open and edit documents from a shell.

## Documentation

The bundled guides cover the [command line](docs/command-line.md),
[documents and files](docs/documents.md), [settings](docs/settings.md),
[language modes](docs/language-modes.md),
[substitution variables](docs/substitution-variables.md), and
[external tools](docs/external-tools.md).

## Data and licensing

The portable ZIP stores settings and application state in the adjacent
`appdata/` directory. Other installations use `%LOCALAPPDATA%\Azunote` by
default.
